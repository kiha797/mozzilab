# 🍡 모찌캡처 — 모찌랩(MozziLab)의 PC 캡처 프로그램

트레이(작업표시줄 오른쪽 아래) 아이콘을 누르면 **캡처 실행창**이 뜨고,
캡처하면 **결과창**에서 바로 편집·저장·복사할 수 있는 Windows용 캡처 프로그램입니다.

---

## 0. 폴더 안의 파일 설명

| 파일 | 하는 일 |
|---|---|
| `1_install.bat` | 처음 한 번만 실행. 필요한 라이브러리를 자동 설치 |
| `2_run.bat` | 프로그램 실행 (개발/테스트용) |
| `3_build_exe.bat` | 다른 PC에 나눠줄 수 있는 **exe 파일** 만들기 |
| `installer.iss` | **설치 프로그램(Setup.exe)** 만들기용 설정 파일 (Inno Setup) |
| `main.py` | 프로그램 시작점 (트레이 아이콘, 단축키) |
| `launcher.py` | 실행창 (취소·직접지정·창·단위영역·전체화면·스크롤·크기지정·캡처목록·메뉴) |
| `overlay.py` | 화면에서 영역을 고르는 화면 (돋보기·좌표·색상 표시) |
| `fixed_frame.py` | 크기지정 캡처 준비창 (**위치와 크기 기억**) |
| `scroll_capture.py` | 스크롤 캡처 (자동 스크롤 후 이어 붙이기) |
| `editor.py` | 결과창 (저장·복사·이전·다시·초기화·도형·펜·더보기·최근 캡처 목록) |
| `config.py` / `settings_dialog.py` | 설정 저장 / 환경설정 창 |
| `ui.py` | 아이콘 그림, 색상, 디자인(스타일), 모찌 캐릭터 |
| `brand.py` | 브랜드 이름, 버전, **웹사이트(서버) 주소** |
| `account.py` | 로그인 · 구독(라이선스) 확인 |
| `ads.py` | 무료 사용자 광고 (배너 · 팝업) |
| `winapi.py` | Windows 기능 (창 찾기, 마우스 휠, 단축키, 자동 실행) |

## 1단계. 파이썬 설치 (PC에 처음 한 번만)

1. 인터넷 브라우저(크롬, 엣지)에서 **https://www.python.org/downloads/** 에 들어갑니다.
2. 노란색 **[Download Python 3.12.x]** (또는 3.13) 버튼을 누릅니다.
3. 다운로드된 `python-3.x.x-amd64.exe`를 더블클릭합니다.
4. ⚠️ **가장 중요**: 첫 화면 맨 아래의
   **☑ Add python.exe to PATH** 체크박스를 **반드시 체크**합니다.
5. **[Install Now]** → 설치가 끝나면 **[Close]**.

> 확인 방법: `Windows 키 + R` → `cmd` 입력 → Enter → 까만 창에 `python --version` 입력 후 Enter.
> `Python 3.12.x` 처럼 나오면 성공입니다.

---

## 2단계. 프로그램 폴더 준비

1. 받은 `MochiCapture.zip` 파일을 **마우스 오른쪽 클릭 → [압축 풀기]** 합니다.
2. 이해하기 쉬운 곳으로 옮깁니다. 예: `C:\MochiCapture`
   - ⚠️ 바탕화면의 `OneDrive` 폴더 안은 피하세요. 동기화 때문에 오류가 날 수 있습니다.

---

## 3단계. 라이브러리 설치

1. `C:\MochiCapture` 폴더에서 **`1_install.bat`를 더블클릭**합니다.
2. "Windows의 PC 보호" 파란 창이 뜨면 → **[추가 정보]** → **[실행]**.
3. 까만 창에서 글자가 쭉 올라갑니다 (3~5분).
4. `설치가 끝났습니다!`가 나오면 아무 키나 눌러 창을 닫습니다.

---

## 4단계. 실행해 보기

1. **`2_run.bat`를 더블클릭**합니다.
2. 화면 위쪽에 **모찌캡처 실행창**이 뜨고, 작업표시줄 오른쪽 아래(시계 옆)에 **파란 아이콘**이 생깁니다.
   - 아이콘이 안 보이면 시계 옆 **`^` (숨겨진 아이콘 표시)** 를 눌러 보세요.
   - 아이콘을 작업표시줄로 끌어다 놓으면 항상 보입니다.
3. 이제부터는 **트레이 아이콘을 클릭하면 실행창이 열립니다.**

## 5단계. 사용 방법

### 실행창 버튼
| 버튼 | 사용법 | 단축키 |
|---|---|---|
| 취소 | 실행창 닫기 | ESC |
| 직접지정 | 마우스로 드래그해서 영역 지정. 드래그 없이 **클릭하면 그 창**이 찍힘 | Ctrl+Shift+C |
| 창 | 마우스를 올리면 창이 파랗게 표시됨 → 클릭 | Ctrl+Shift+W |
| 단위영역 | 창 안의 버튼·패널·입력칸 같은 작은 영역 단위로 선택 | Ctrl+Shift+D |
| 전체화면 | 마우스가 있는 모니터 전체를 바로 캡처 | Ctrl+Shift+A |
| 스크롤 | 스크롤할 창 클릭(또는 영역 드래그) → 자동으로 내리면서 길게 캡처. **ESC로 중지** | Ctrl+Shift+S |
| 크기지정 | 파란 틀을 원하는 위치·크기로 맞추고 **[캡처]** 또는 **Enter** | Ctrl+Shift+F |
| 캡처목록 | 결과창(최근 캡처 목록) 열기 | |
| 메뉴 | 환경설정, 저장 폴더 열기, 단축키 안내, 종료 | |

- `PrintScreen` 키 = 직접지정 (환경설정에서 다른 기능으로 변경 가능) (Windows 11은 PrtSc가 '캡처 도구'에 잡혀 있을 수 있음 → 아래 '문제 해결' 참고)
- 실행창이 떠 있을 때 숫자 **1~6** 키로 바로 캡처 방식 선택 가능

### ⭐ 크기지정 (요청하신 핵심 기능)
- 파란 틀 **안쪽을 끌면 이동**, **테두리/모서리를 끌면 크기 조절**
- 아래 막대에 가로·세로 숫자 직접 입력 또는 `크기 선택`(1920x1080 등) 선택
- 키보드 방향키 = 1픽셀 이동, `Shift+방향키` = 10픽셀 이동
- **마지막 위치와 크기를 자동으로 기억**합니다 → 다음에 크기지정을 누르면 **같은 자리, 같은 크기로** 열립니다.
  (프로그램을 껐다 켜도, PC를 재부팅해도 유지)

### 결과창
- **새캡처**(Ctrl+N) · **저장**(Ctrl+S) · **복사**(Ctrl+C) · **이전**(Ctrl+Z) · **다시**(Ctrl+Y) · **초기화**(처음 캡처 상태로)
- **도형** 버튼 옆 ▾ : 사각형 / 원 / 직선 / 화살표 선택 → 이미지 위에 드래그
- **펜** 버튼 옆 ▾ : 펜 / 형광펜
- **더보기** : 텍스트, 모자이크(개인정보 가리기), 자르기, 이미지 파일 열기, 인쇄, 저장 폴더 열기, 환경설정
- 도구를 고르면 아래 줄에 **색상·두께·채우기**가 나타납니다. `Shift`를 누른 채 그리면 정사각형/수평선이 됩니다.
- 아래쪽: `이미지 사이즈`, **－ / ＋** 확대·축소, **원본크기**, **창맞춤** (Ctrl+마우스휠로도 확대·축소)
- 오른쪽 **최근 캡처 목록 [n장/100장]** : 클릭하면 다시 열어서 편집. 편집한 내용은 자동으로 목록에 반영됩니다.
  - `선택` → 여러 장 고른 뒤 `선택 저장`/`선택 삭제`
  - 썸네일 오른쪽 클릭 → 열기 / 다른 이름으로 저장 / 복사 / 삭제
- 캡처하면 **자동으로 클립보드에 복사**되므로 카톡·메일·엑셀에 바로 `Ctrl+V` 할 수 있습니다.

### 실행창 [메뉴] 버튼
| 항목 | 설명 |
|---|---|
| 캡처 실행창 보기 | 끄면 트레이 아이콘을 클릭했을 때 실행창 대신 **캡처 메뉴**가 뜹니다 |
| 자동 복사 | 캡처하면 클립보드로 자동 복사 |
| 자동 저장 | 캡처하면 저장위치에 파일로 자동 저장 |
| 환경설정 / 도움말 | 설정 창 / 현재 단축키 목록 |

### 환경설정 (메뉴 → 환경설정) — 알캡처와 같은 4개 화면
**① 일반 설정**
- 기본 설정: 화면 오버레이(어둡게) 표시 · 캡처 실행창 숨김(메뉴로 대체) · 캡처 후 저장창 바로 띄우기 · Windows 시작 시 자동 실행 · 종료버튼 클릭 시 트레이로 최소화 (끄면 X = 프로그램 종료)
- 캡처 설정: 캡처 후 결과창 띄우지 않기 · 항상 클립보드로 복사 · 저장완료 안내창(오른쪽 아래 알림) · 마우스 커서 포함 (스크롤 캡처 제외)
- 가이드라인 설정: 선택 표시선 색(빨강/주황/노랑/초록/파랑/보라/검정/흰색) · 캡처 이미지에 표시선 유지

**② 고급 설정**
- 이미지 저장: 파일 포맷(PNG/JPG/BMP), 품질(JPG일 때만), **[파일명 설정]** (앞 글자 예: `동원`, 날짜 형식, 일련번호 001·002…)
- 자동저장: 사용 여부와 저장위치
- **크기지정 캡처 프리셋**: 자주 쓰는 크기를 최대 6개 등록 → 크기지정 창의 `크기 선택` 맨 위에 ★ 표시로 나옵니다
- 스크롤 캡처 대기시간

**③ 단축키 설정**
- PrintScreen 키를 [실행창 열기 / 직접 지정 / 창 / 단위영역 / 전체 / 스크롤 / 크기지정] 중 원하는 기능으로 사용
- 6가지 캡처마다 켜기/끄기, 윈도 키·Ctrl·Shift·Alt 조합과 글자 키를 자유롭게 지정 (겹치는 조합이나 조합키 없는 글자는 경고)
- 기본값: Ctrl+Shift + C(직접지정) / W(창) / D(단위영역) / A(전체) / S(스크롤) / **F(크기지정)**

**④ 캡처목록 설정**
- 목록 비우기 시 알림창 · 모두 저장 완료 안내창 · 삭제 시 알림창
- 목록이 가득 찼을 때 오래된 이미지 자동 삭제 (끄면 가득 찼을 때마다 물어봄) · 최대 보관 장수

**[기본값으로]** 버튼: 현재 화면만 또는 전체를 처음 설정으로 되돌립니다.

## ⭐ 로그인 · 광고 · 구독 (모찌 플러스)

- **무료 사용자**: 결과창 오른쪽 위에 **배너 광고 + [자세히 알아보기]** 버튼, 캡처 직후 왼쪽 아래에 **팝업 광고**(✕로 닫기)가 나옵니다.
- 결과창 오른쪽 위 **[로그인]** → 작은 창에 **8자리 코드**가 뜨고 웹브라우저가 자동으로 열립니다
  → 웹에서 로그인(또는 회원가입) → 코드가 같은지 확인 → **[연결 승인]** → PC가 자동으로 로그인됩니다.
- **모찌 플러스(월 5,500원)** 구독 계정으로 로그인하면 광고가 **즉시 사라집니다**.
- 로그인 후 계정 버튼(`⭐ 홍길동 님 ▾`) 메뉴: 마이페이지 / 광고 없이 쓰기 / 구독 상태 새로고침 / 로그아웃
- 실행창 [메뉴]와 트레이 메뉴에도 로그인/로그아웃이 있습니다.
- 프로그램은 3시간마다 구독 상태를 다시 확인합니다. 인터넷이 끊겨도 마지막 확인 후 **7일 동안은** 구독 상태가 유지됩니다.
- 웹 마이페이지(또는 관리자)에서 PC를 '해제'하면 그 PC는 자동으로 로그아웃됩니다.

## 6단계. exe 파일 만들기 (파이썬 없는 PC에도 설치하려면)

1. **`3_build_exe.bat`를 더블클릭** → 1~3분 기다립니다.
2. 끝나면 `dist\MochiCapture` 폴더가 자동으로 열립니다. 안의 **`MochiCapture.exe`** 가 완성된 프로그램입니다.
   - 이 `MochiCapture` 폴더 **통째로** 복사하면 다른 PC에서도 실행됩니다 (파이썬 설치 불필요).

### (선택) 설치 프로그램 `Setup.exe` 만들기
1. **https://jrsoftware.org/isdl.php** → `innosetup-6.x.x.exe` 다운로드 → 설치 (기본값으로 [다음]만 누르면 됨)
2. `installer.iss`를 **더블클릭** (Inno Setup이 열림)
3. 위 메뉴 **[Build] → [Compile]** (또는 `Ctrl+F9`)
4. `installer_output\MochiCapture_Setup_1.0.0.exe` 가 생깁니다.
   이 파일 하나만 직원들에게 배포하면 됩니다. (시작 메뉴·바탕화면 바로가기·자동 실행 선택 가능, 제어판에서 제거 가능)

## 문제 해결

| 증상 | 해결 |
|---|---|
| `1_install.bat` 에서 "파이썬이 설치되어 있지 않습니다" | 1단계를 다시. **Add python.exe to PATH** 체크 필수. 설치 후 PC 재시작 |
| 더블클릭하면 Microsoft Store가 열림 | 설정 → 앱 → 고급 앱 설정 → **앱 실행 별칭** → `python.exe`, `python3.exe` 끄기 |
| PrintScreen 키가 안 먹음 | 설정 → 접근성 → 키보드 → **"Print Screen 키를 사용하여 화면 캡처 열기" 끄기** 후 모찌캡처 재실행 |
| Ctrl+Shift+C 등이 다른 프로그램과 겹침 | 환경설정 → 단축키 설정에서 다른 조합으로 바꾸거나 체크 해제 |
| 스크롤 캡처가 일찍 멈추거나 끊김 | 환경설정 → 스크롤 대기시간을 700~1000ms로 늘리기. 위에 고정된 메뉴바가 있는 웹페이지는 메뉴바 아래 영역만 드래그해서 지정 |
| 백신이 exe를 막음 | PyInstaller로 만든 exe는 가끔 오탐됩니다. 사내 백신 예외 등록 또는 코드서명 인증서 적용 |
| 설정 초기화하고 싶음 | `Windows 키 + R` → `%APPDATA%\MochiCapture` → `config.json` 삭제 |

## 저장 위치
- 설정: `%APPDATA%\MochiCapture\config.json` (크기지정 위치/크기도 여기 저장)
- 최근 캡처 목록: `%APPDATA%\MochiCapture\history\`
