# 🍡 모찌PDF — 모찌랩(MozziLab)

## 할 수 있는 일
| 도구 | 설명 |
|---|---|
| 합치기 | 여러 PDF를 끌어다 놓고 순서를 바꾼 뒤 한 파일로 |
| 나누기 | 한 쪽씩 / N쪽씩 / 범위마다 / 고른 쪽만 뽑기 (예: `1-3, 5, 8-`) |
| 페이지 편집 | 미리보기를 보며 끌어서 순서 바꾸기, 돌리기, 지우기 |
| 이미지→PDF | 사진·스캔 이미지를 원본 크기 또는 A4로 |
| PDF→이미지 | 쪽마다 PNG/JPG (96/150/300dpi) |
| 용량 줄이기 | 그림 화질·크기를 줄여 메일·카톡용으로 (원본은 그대로) |
| 암호 | AES-256 암호 걸기 / 아는 암호 풀기 |

- PDF 파일을 창에 끌어다 놓으면 바로 열립니다. 여러 개면 '합치기', 이미지면 '이미지→PDF'로 갑니다.
- 설치하면 PDF 파일 오른쪽 클릭 메뉴에 **"모찌PDF로 열기"** 가 생깁니다.

## 설치
- **일반 사용자**: https://mozzilab.labelpos.com 에서 **무료 다운로드** → `MochiPDF_Setup.exe` 실행
- **직접 실행(개발)**: 파이썬 설치 후 이 폴더의 `1_install.bat` → `2_run.bat`
- **exe 만들기**: `3_build_exe.bat` (GitHub 에서는 Actions 의 "설치파일 만들기"가 자동으로 만듭니다)

## 로그인 · 광고
모찌캡처와 같습니다. 오른쪽 위 **[로그인]** → 웹에서 [연결 승인] → **모찌 플러스** 구독 계정이면 광고가 사라집니다.
같은 PC 에서 모찌캡처 · 모찌PDF · 모찌압축을 함께 써도 **PC 1대**로 계산됩니다.

> 세 프로그램이 함께 쓰는 코드(로그인·광고·디자인)는 저장소의 `shared` 폴더에 있습니다.
