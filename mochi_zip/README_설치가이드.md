# 🍡 모찌압축 — 모찌랩(MozziLab)

## 할 수 있는 일
- **압축하기**: 파일·폴더를 끌어다 놓고 ZIP 또는 7Z 로 (압축 정도: 빠르게/보통/최대, 암호 AES-256)
- **압축 파일 열기**: 안의 파일을 폴더 구조로 보고, 전부 또는 골라서 풀기
- **바로 풀기**: 같은 폴더에 `파일이름` 폴더를 만들어 풀기
- 지원 형식: ZIP · 7Z · TAR · TAR.GZ · TAR.BZ2 · TAR.XZ (RAR 은 아직 미지원)
- Windows 탐색기로 만든 ZIP 의 **깨진 한글 파일 이름을 자동으로 바로잡습니다**
- 위험한 경로(`../`)가 든 압축 파일은 폴더 밖으로 풀리지 않게 막습니다

## 마우스 오른쪽 클릭 메뉴 (설치하면 자동 추가)
| 위치 | 메뉴 |
|---|---|
| ZIP · 7Z 파일 | 모찌압축으로 여기에 풀기 / 모찌압축으로 열기 |
| 모든 파일 · 폴더 | 모찌압축으로 압축하기 (같은 폴더에 `.zip` 생성) |

> Windows 11 은 오른쪽 클릭 후 **"추가 옵션 표시"** 를 누르면 보입니다.

## 설치
- **일반 사용자**: https://mozzilab.labelpos.com 에서 **무료 다운로드** → `MochiZip_Setup.exe` 실행
- **직접 실행(개발)**: 파이썬 설치 후 이 폴더의 `1_install.bat` → `2_run.bat`
- **exe 만들기**: `3_build_exe.bat` (GitHub 에서는 Actions 의 "설치파일 만들기"가 자동으로 만듭니다)

## 로그인 · 광고
모찌캡처와 같습니다. 오른쪽 위 **[로그인]** → 웹에서 [연결 승인] → **모찌 플러스** 구독 계정이면 광고가 사라집니다.
같은 PC 에서 모찌캡처 · 모찌PDF · 모찌압축을 함께 써도 **PC 1대**로 계산됩니다.

> 세 프로그램이 함께 쓰는 코드(로그인·광고·디자인)는 저장소의 `shared` 폴더에 있습니다.
